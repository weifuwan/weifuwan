I enjoy turning complex data integration problems into simple, usable products — from frontend experience and backend services to big data runtime, job scheduling, observability, and deployment.

## 🚀 Featured Project

### 🌊 [SeaTunnel Web](https://github.com/weifuwan/seatunnel-web)

A modern data synchronization and integration console for Apache SeaTunnel.

<p>
  <a href="https://github.com/weifuwan/seatunnel-web">
    <img src="https://github-readme-stats.vercel.app/api/pin/?username=weifuwan&repo=seatunnel-web&theme=tokyonight" />
  </a>
</p>

**Core Capabilities**

* 🔌 Data source management and connection testing
* 🧩 Visual job creation and configuration
* ⏱️ Job scheduling and execution management
* 📈 Runtime metrics, logs, and observability
* 🌊 Batch and real-time data synchronization
* 🛠️ Built with React, Spring Boot, Quartz, WebSocket, and SeaTunnel Zeta
