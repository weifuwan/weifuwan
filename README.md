---

### 我相信的几件事

**工具最终应该解决问题。**  技术栈不是目的，真正有人使用、真正减少工作量才有价值。

**复杂的系统应该被做简单。**  数据平台已经足够复杂，我更想做的是减少复杂度，而不是制造复杂度。

**AI 会改变软件开发，但不会替代判断。**  代码越来越容易生成，真正稀缺的是知道该做什么、为什么做，以及什么不应该做。

**做出来，比讨论出来更重要。**  所以我喜欢直接做项目、跑起来、不断改，让想法最后变成能用的东西。
